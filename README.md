## Thorns of the Shrike

Thorns of the Shrike is a personal project for a roleplaying community of 100+ people which I run with a few friends. This app includes the following features:

- Roll dice in compliance with the TotS system rules
- Display and store dice rolls for other users to view
- Update dice rolls others make in real time
- Utilize the "Quick Roll" section to quickly roll dice

Link to the live site: [https://shrike-web-client.vercel.app/web-rolls-shrikes](https://shrike-web-client.vercel.app/web-rolls-shrikes)

## Getting Started

To run locally, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
